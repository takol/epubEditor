EPUB Builder 隱私權政策

最後更新日期：2026 年 10 月 1 日

歡迎使用 EPUB Builder（以下簡稱「本應用程式」）。我們非常重視您的隱私權。本政策旨在向您說明我們如何收集、使用、儲存及保護您的個人資料，特別是當您使用第三方帳號（如 Google 帳號）授權登入時的資料處理方式。

1. 我們收集的資訊

本應用程式為客戶端純靜態執行工具，我們致力於最小化資料收集：

  • Google 帳號資訊（若啟用 OAuth 登入）：當您透過 Google OAuth 授權登入時，本應用程式僅會取得您同意授權的基本識別資料（如：您的 Google 帳號 ID、電子郵件地址及公開個人資料圖片），用於辨識身分與維護使用工作階段。
  • 本機儲存資料（Local Storage）：您在製作電子書過程中所編輯的文字、章節設定及暫存檔案，預設僅儲存在您所使用的瀏覽器本機端（IndexedDB 或 LocalStorage），我們不會將其自動上傳至任何私人後端資料庫。

2. 資訊的使用方式

我們收集的必要資訊僅用於：

  • 提供與維持電子書轉換及編輯工具的正常運作。
  • 確認使用者授權狀態與權限控管。
  • 持續優化前端效能與使用者操作體驗。

3. Google API 資料使用特別聲明（Limited Use Policy）

本應用程式對自 Google API 接收到的任何資訊之使用與移轉至任何其他應用程式，均嚴格遵守 Google API 服務使用者資料政策，包括其中的「限制使用（Limited Use）」要求。
  • 我們不會將您的 Google 使用者資料出售給任何第三方。
  • 我們不會將您的資料用於廣告投放或提供給資料仲介公司。
  • 除為實現您主動要求的電子書匯入/匯出功能所必需外，人類無法直接閱讀或檢視您的 Google 檔案或私人資料。

4. 資料儲存與安全

本應用程式架設於 GitHub Pages 靜態代管平台，所有與本網站的連線傳輸皆全面透過 HTTPS 安全加密通訊協議進行。未經您的授權同意，您的內容不會在傳輸過程中洩漏給非相關方。

5. 第三方服務與對外連結

本應用程式可能包含第三方外掛程式或對外連結（如 Google OAuth 服務、GitHub 等）。這些外部服務皆具備各自獨立的隱私權條款，建議您在使用該外部服務前詳細參閱其政策說明。

6. 使用者的權利

您對您的資料保有完全的控制權：

  • 您可以隨時前往 Google 帳戶安全設定 撤銷對本應用程式的所有存取授權。
  • 您可以隨時清除瀏覽器快取及本機儲存空間，以徹底刪除暫存於您裝置上的所有電子書編輯進度。

7. 政策修訂

我們可能會因應法規變更或功能調整，隨時修訂本隱私權政策。最新版本將公佈於此頁面，並標註修訂日期。
